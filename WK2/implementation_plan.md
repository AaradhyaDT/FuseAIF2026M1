# Week 3 Roadmap Implementation: AI-Powered Query Interface

This plan outlines the architecture for transforming the existing Customer API into an intelligent, AI-powered natural language query interface, as described in the Week 3 Roadmap.

## Goal Description

The objective is to implement a system that takes natural language queries from users, determines which tables and columns are required, generates an optimized SQL query, executes it against the PostgreSQL database, and finally processes the structured results back into a natural language response using a Large Language Model (LLM).

## Proposed Changes

### 1. Complete Remaining Core CRUD
The roadmap shows a ✅ next to "Extend CRUD operations to **all tables**", but currently, only the `Customers` router has full CRUD. If desired, I will:
- Generate schemas (`schemas.py`), CRUD logic (`crud.py`), and routers for **Orders**, **Payments**, **Products**, **ProductLines**, **Employees**, **Offices**, and **OrderDetails**.

### 2. LLM Integration & Query Intelligence Layer
We will introduce a new service layer dedicated to interacting with an LLM.

- **[NEW] `app/ai/llm_service.py`**:
  - Integrate an LLM provider (e.g., OpenAI, Anthropic, Gemini).
  - Define prompts for **Table & Schema Intelligence**: Provide the LLM with our SQLAlchemy models/database schema so it knows what data is available.
  - Define prompts for **Query Decomposition & SQL Generation**: Convert the natural language request into a valid PostgreSQL SQL query.

### 3. Query Execution Engine
- **[NEW] `app/ai/query_engine.py`**:
  - Take the SQL query generated by the LLM.
  - Validate the query to prevent destructive operations (e.g., ensuring only `SELECT` statements are executed, preventing SQL injection).
  - Execute the raw query using SQLAlchemy's `text()` construct against the database.
  - Fetch the structured data (rows).

### 4. Natural Language Response Generation
- In `llm_service.py`, pass the raw structured data back to the LLM along with the user's original question to generate a human-readable, intelligent summary.

### 5. New API Endpoint
- **[NEW] `app/ai_router.py`**:
  - `POST /ask`: An endpoint accepting a payload like `{"query": "Who are our top 5 customers by order volume?"}`.
  - This endpoint will orchestrate the full pipeline: User Query ➡️ LLM SQL Generation ➡️ DB Execution ➡️ LLM Natural Language Formatting ➡️ Final Response.
